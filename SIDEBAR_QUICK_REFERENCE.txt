  1️⃣ 메뉴 순서 변경
     → navigation.ts에서 배열 순서 변경

  2️⃣ 권한 변경
     → roles: ['ADMIN'] → roles: ['ADMIN', 'DISPATCHER']

  3️⃣ 모바일 표시/숨김
     → mobileVisible: true / false

  4️⃣ 서브메뉴 추가
     → children: [...] 배열 추가

  5️⃣ 아이콘 변경
     → icon: Home → icon: Star

┌────────────────────────────────────────────────────────────────┐
│ 🧪 테스트 방법                                                  │
└────────────────────────────────────────────────────────────────┘

  1. 빌드 테스트
     cd /root/uvis/frontend
     npm run build

  2. 브라우저 테스트
     - http://139.150.11.99 접속
     - Ctrl+F5 (강제 새로고침)
     - 로그인 후 메뉴 확인

  3. 권한 테스트
     - ADMIN 계정: 모든 메뉴 보임
     - DISPATCHER 계정: 제한된 메뉴

  4. 모바일 테스트
     - F12 > 모바일 뷰
     - 하단 네비게이션 5개 아이템 확인

┌────────────────────────────────────────────────────────────────┐
│ 🔧 트러블슈팅                                                   │
└────────────────────────────────────────────────────────────────┘

  ❌ 빌드 에러
     → npx tsc --noEmit (타입 체크)
     → npm install (재설치)

  ❌ 메뉴 안 보임
     → roles 배열 확인
     → 브라우저 캐시 삭제

  ❌ 모바일 메뉴 안 보임
     → mobileVisible: true 설정

  ❌ 변경사항 반영 안 됨
     → docker-compose down
     → docker system prune -f
     → 재배포
