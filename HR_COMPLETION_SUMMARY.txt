🎯 핵심 기능
────────────────────────────────────────────────────────────────────

✅ 조직 계층 관리
   MASTER (총괄) → ADMIN (관리자) → MANAGER → DRIVER (운전직)
   
✅ 통합 인사카드
   기본정보 | 근무정보 | 자격증 | 급여정보 (4개 탭)
   
✅ 운전자 풀 자동 연동
   Employee (role=DRIVER) → Driver Pool → Vehicle Assignment
   
✅ 🆕 지게차 운전능력 관리 (핵심 신규 기능)
   - can_drive_forklift: 실제 운전 가능 여부 (배차용)
   - has_forklift_certificate: 자격증 보유 여부 (법적 요건)
   - 자격증과 별개로 운전 실태 파악 가능

────────────────────────────────────────────────────────────────────
🆕 신규 데이터베이스 필드
────────────────────────────────────────────────────────────────────

Employee 모델에 추가:
  • can_drive_forklift (Boolean) - 지게차 운전 가능 여부
  • has_forklift_certificate (Boolean) - 자격증 보유 여부
  • forklift_certificate_number (String) - 자격증 번호
  • forklift_certificate_issue_date (Date) - 발급일
  • forklift_certificate_expiry_date (Date) - 만료일

4가지 상태:
  1. ✅✅ 운전 가능 + 자격증 보유 → 1순위 배차
  2. ✅⚠️ 운전 가능 + 자격증 미보유 → 2순위 (교육 대상)
  3. ❌✅ 운전 불가 + 자격증 보유 → 3순위 (복귀 대기)
  4. ❌❌ 운전 불가 + 자격증 미보유 → 4순위 (신규 채용)

🔌 주요 API 엔드포인트
────────────────────────────────────────────────────────────────────

기본 CRUD:
  GET    /api/v1/employees              # 목록 조회
  POST   /api/v1/employees              # 신규 등록
  GET    /api/v1/employees/{id}         # 상세 조회
  PUT    /api/v1/employees/{id}         # 정보 수정
  DELETE /api/v1/employees/{id}         # 삭제

운전자 특화:
  GET    /api/v1/employees/drivers                   # 운전직 조회
  GET    /api/v1/employees/drivers/available         # 배차 가능
  GET    /api/v1/employees/drivers/forklift-capable  # 지게차 가능

필터 예시:
  ?can_drive_forklift=true&has_forklift_certificate=true
  → 지게차 운전 가능 + 자격증 보유
  
  ?can_drive_forklift=true&has_forklift_certificate=false
  → 지게차 운전 가능 + 자격증 미보유 (교육 대상)
