  ✓ 운전자 배정됨
  ✓ 운전자 배정 안됨

사용 예시:
  1. 미배정 차량 찾기:
     → "운전자 배정 안됨" 선택
     → 운전자가 필요한 차량만 표시
  
  2. 배정 완료 차량 확인:
     → "운전자 배정됨" 선택
     → 이미 배정된 차량만 표시
  
  3. 복합 필터링:
     → 냉동 + 운행가능 + 배정 안됨
     → 즉시 배정 가능한 냉동 차량만 표시
