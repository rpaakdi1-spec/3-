🚀 Option 1: 자동 스크립트 실행 (가장 간단!) - 추천
═══════════════════════════════════════════════════════════════════════

서버에서 단 한 줄로 모든 작업 완료:

    cd /root/uvis && curl -O http://139.150.11.99/uvis_frontend.tar.gz && \
    tar -xzf uvis_frontend.tar.gz && \
    bash <(cat <<'SCRIPT'
    # OrdersPage.tsx 수정
    python3 - <<'PYEOF'
import sys
file_path = '/root/uvis/frontend/src/pages/OrdersPage.tsx'
with open(file_path, 'r', encoding='utf-8') as f:
    content = f.read()
old = """        </div>
      )}
  );
};"""
new = """        </div>
      )}
    </>
  );
};"""
if old in content:
    content = content.replace(old, new)
    with open(file_path, 'w', encoding='utf-8') as f:
        f.write(content)
    print("✅ OrdersPage.tsx OK")
else:
    print("⚠️  Already fixed or different")
PYEOF

    # .dockerignore 수정
    sed -i '/^# Build output/d' /root/uvis/frontend/.dockerignore
    sed -i '/^dist$/d' /root/uvis/frontend/.dockerignore
    sed -i '/^build$/d' /root/uvis/frontend/.dockerignore
    
    # 빌드 & 배포
    cd /root/uvis/frontend && npm run build && cd /root/uvis
    docker-compose stop frontend && docker-compose rm -f frontend
    docker rmi uvis-frontend 2>/dev/null || true
    docker-compose build --no-cache frontend
    docker-compose up -d frontend
    sleep 15
    docker exec uvis-frontend ls -lh /usr/share/nginx/html/assets/*.css
    echo "✅ 완료!"
SCRIPT
)
