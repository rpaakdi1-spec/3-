🚀 Dispatch Rules API Tester

배차 규칙 API 테스트 도구 - PUT 요청 형식 확인

⚠️ 중요: PUT 요청은 {"rule_update": {...}} wrapper가 필요합니다!

📋 요청 형식 비교

❌ 잘못된 형식 (422 에러)
{ "name": "규칙명", "priority": 100 }
✅ 올바른 형식 (200 성공)
{ "rule_update": { "name": "규칙명", "priority": 100 } }

1️⃣ 규칙 목록 조회 (GET)

2️⃣ 단일 규칙 조회 (GET)

3️⃣ 규칙 수정 - 잘못된 형식 (422 예상)

4️⃣ 규칙 수정 - 올바른 형식 (200 예상)

5️⃣ 규칙 삭제 (DELETE)

⚠️ 주의: 삭제는 실제로 수행됩니다. 테스트용 규칙에만 사용하세요!
