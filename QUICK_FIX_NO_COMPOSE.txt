문제: docker-compose에 uvis-frontend 서비스 없음

해결: 컨테이너 이름을 찾아서 직접 재시작

================================================================================
방법 1: 자동으로 찾아서 재시작 (가장 쉬움!)
================================================================================

서버에서 다음 명령어 복사 & 실행:

bash <(cat << 'SCRIPT'
cd /root/uvis
CONTAINER=$(docker ps --format "{{.Names}}" | grep -iE "frontend|nginx|web" | head -1)
echo "찾은 컨테이너: $CONTAINER"
docker restart $CONTAINER
sleep 10
docker logs $CONTAINER --tail 20
echo ""
echo "🎉 완료! http://139.150.11.99/dispatch-rules 테스트하세요!"
SCRIPT
)

================================================================================
방법 2: 수동으로 컨테이너 이름 확인 후 재시작
================================================================================

1. 실행 중인 컨테이너 보기:
   docker ps

2. 프론트엔드 컨테이너 이름 찾기 (예: uvis-web, nginx, frontend 등)

3. 재시작 (컨테이너 이름을 실제 이름으로 바꾸세요):
   docker restart [컨테이너이름]

4. 로그 확인:
   docker logs [컨테이너이름] --tail 20

================================================================================
예상되는 컨테이너 이름
================================================================================

다음 중 하나일 가능성이 높습니다:
  - uvis-web
  - uvis-nginx  
  - uvis_frontend
  - nginx
  - web
  - frontend

================================================================================
빌드된 파일 직접 복사하는 방법 (대안)
================================================================================

Docker 없이 빌드된 파일을 직접 Nginx에 복사:

cd /root/uvis/frontend
# 기존 파일 백업
cp -r /usr/share/nginx/html /usr/share/nginx/html.backup.$(date +%Y%m%d_%H%M%S)
# 새로 빌드된 파일 복사
cp -r dist/* /usr/share/nginx/html/
# Nginx 재시작
nginx -s reload

또는 systemctl restart nginx

================================================================================
테스트
================================================================================

1. 브라우저 캐시 클리어 (필수!)
   Ctrl + Shift + Delete → 캐시 삭제

2. URL 접속
   http://139.150.11.99/dispatch-rules

3. 규칙 수정 테스트
   규칙 선택 → 수정 → 저장
   ✅ 성공!

4. F12 개발자 도구 확인
   Network 탭 → PUT 요청
   Payload: {"rule_update": {...}} ✅
   Response: 200 OK ✅

================================================================================
문제 해결
================================================================================

Q: 컨테이너를 찾을 수 없어요
A: docker ps 실행 후 결과를 확인하고, 
   프론트엔드 관련 컨테이너 이름을 찾아서 직접 재시작하세요

Q: 여전히 422 에러가 나요
A: 1) 브라우저 캐시 완전 삭제
   2) 시크릿 모드로 테스트
   3) dist 폴더가 제대로 빌드되었는지 확인
      ls -lh /root/uvis/frontend/dist/

Q: 빌드는 성공했는데 변경사항이 안 보여요
A: 1) 브라우저 강력 새로고침 (Ctrl + Shift + R)
   2) 캐시 완전 삭제 후 재접속
   3) 시크릿 모드로 테스트
